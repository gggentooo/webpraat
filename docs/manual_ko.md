## 1. 소개

### WebPraat이란?
**WebPraat (웹프랏)**은 전 세계 음성학계의 표준 분석 도구인 데스크톱 **Praat** 프로그램(네덜란드 암스테르담 대학교의 Paul Boersma와 David Weenink 개발)을 최신 웹 브라우저 환경에서 직접 실행할 수 있도록 이식한 시스템입니다. 별도의 프로그램 설치나 복잡한 컴파일 과정 없이, 웹 브라우저 안에서 원본 Praat의 실제 디지털 신호 처리(DSP) 엔진을 구동하여 음향 측정, 분절 전사, 피치 추적, 포먼트 분석, 스펙트럼 분석을 동일한 정확도로 수행할 수 있습니다.

### 화면 구성 개요
WebPraat을 열면 다음과 같이 기능별로 나뉜 통합 작업 환경이 나타납니다:

1. **상단 메뉴 바 (Menu Bar)**: 전역 파일 작업, 마이크 녹음, 신호 합성, 파일 저장, 스크립트 생성, 작업 공간 관리 및 언어 전환을 제공합니다.
2. **좌측 창 (Praat 객체 Window)**:
   - **객체 목록 (Objects)**: 불러오거나 계산된 모든 항목(`Sound`, `TextGrid`, `Pitch`, `Formant`, `Spectrogram` 등)을 번호와 함께 나열합니다.
   - **동적 동작 모음 (Dynamic Action Bar)**: 현재 선택된 객체 유형(또는 객체 조합)에 맞춰 실행 가능한 버튼들이 자동으로 변경되어 나타납니다.
   - **고정 하단 버튼**: 객체 관리를 위한 기본 도구(`이름 변경...`, `복사...`, `검사 (Inspect)`, `정보 (Info)`, `제거 (Remove)`)가 상시 배치되어 있습니다.
3. **우측 창 (작업 공간 / 에디터 / 그림창)**:
   - **탭**: `Praat 그림 (Picture)`, 실행 중인 `사운드 에디터`, 실행 중인 `TextGrid 에디터`, `Praat 스크립트` 콘솔 간을 자유롭게 전환합니다.
   - **에디터 캔버스**: 마우스로 조작 가능한 반응형 음향 파형, 스펙트로그램 및 주석 전사 층(Tier) 캔버스입니다.
4. **우측 하단 (Praat 정보 Window)**:
   - 음향 측정 수치(구간 길이, 기본주파수, 포먼트 주파수, 스크립트 출력 결과)가 출력되는 텍스트 콘솔이며, 원클릭 **복사** 및 **지우기** 기능을 지원합니다.

### 개인정보 보호 및 로컬 연산 안내
> [!NOTE]
> WebPraat에서 수행하는 모든 음성 분석, 마이크 녹음, 오디오 재생 및 스크립트 연산은 **사용자의 컴퓨터 웹 브라우저 내부에서 100% 로컬로 처리**됩니다. 사용자의 음성 녹음 데이터나 텍스트 전사 파일은 외부 서버로 전송되거나 저장되지 않으므로 안심하고 연구 및 수업에 활용할 수 있습니다.

## 2. 상단 메뉴 바 참조

화면 최상단의 메뉴 바는 작업 목적에 따라 분류된 핵심 기능들을 제공합니다:

### Praat 메뉴
- **새 Praat 스크립트**: 빈 스크립트 에디터를 열고 `untitled.praat`라는 이름의 새로운 자동화 배치 스크립트를 작성합니다.
- **Praat 스크립트 열기...**: 사용자 컴퓨터에 저장된 기존 Praat 스크립트 파일(`.praat`, `.psc`, `.txt`)을 스크립트 탭으로 불러옵니다.
- **로컬 폴더 마운트...**: 웹 브라우저의 File System Access API를 통해 컴퓨터의 로컬 디렉토리를 가상 작업 환경(`/workspace/<폴더이름>`)에 마운트합니다. 스크립트가 로컬 음성 파일을 읽고 전사한 `.TextGrid` 파일을 하드 드라이브에 직접 저장할 수 있게 됩니다.
- **작업 공간 저장 (OPFS)**: 현재 불러온 모든 Praat 객체와 작성 중인 스크립트 코드를 브라우저의 비공개 오프라인 저장소(OPFS)에 즉시 저장합니다.
- **저장된 작업 공간 초기화**: 브라우저 오프라인 저장소에 보관된 작업 공간 데이터를 삭제합니다.
- **정보창 지우기**: Praat 정보창(Info)에 출력되어 있는 모든 텍스트 내용을 말끔히 지웁니다.
- **소스 코드 (GitHub)**: 공식 WebPraat 오픈소스 저장소를 새 브라우저 탭에서 엽니다.

### 새로 만들기 메뉴
- **모노 사운드 녹음...**: 1채널 모노 마이크 입력을 캡처하는 사운드 녹음기(SoundRecorder) 창을 엽니다.
- **스테레오 사운드 녹음...**: 2채널 스테레오 오디오를 캡처하는 녹음기 창을 엽니다.
- **단일 순음(Pure tone) 사운드 생성...**: 객체 이름, 주파수(Hz), 길이(초), 샘플링 주파수(Hz), 진폭(0~1)을 지정하여 합성 사인파 사운드를 생성합니다.
- **모음으로부터 KlattGrid 생성...**: 표준 음향 포먼트 기본값(F1, F2, F3, F4)과 기본주파수(F0)가 초기 설정된 Klatt 음성 합성기 파라미터 그리드를 생성합니다.
- **화자(Speaker) 모델 생성...**: 조음 음성 합성을 위한 화자 모델(여성, 남성, 아동)을 생성합니다.
- **조음 동작(Artword) 생성...**: 음성 합성을 위한 성도 조음 기관의 움직임 제어 타깃을 생성합니다.

### 열기 메뉴
- **파일에서 읽기...**: 컴퓨터에 저장된 오디오 파일(`.wav`, `.mp3`, `.flac`, `.ogg`, `.aiff`) 또는 전사 파일(`.TextGrid`)을 불러옵니다. 파일을 객체 목록 위로 직접 끌어다 놓아도 동일하게 열립니다.
- **로컬 폴더 마운트...**: 대량의 음성 파일을 스크립트로 일괄 처리하기 위해 로컬 작업 폴더를 연결하는 바로가기입니다.

### 저장 메뉴
- **WAV 파일로 저장...**: 현재 선택된 `Sound` 객체를 표준 비압축 16비트 PCM `.wav` 오디오 파일로 컴퓨터의 다운로드 폴더에 저장합니다. *(Sound 객체가 선택된 경우에만 활성화됩니다.)*
- **TextGrid 파일로 저장...**: 현재 선택된 `TextGrid` 객체를 표준 Praat 텍스트 포맷의 `.TextGrid` 파일로 저장합니다. *(TextGrid 객체가 선택된 경우에만 활성화됩니다.)*

### 도움말 메뉴
- **Praat 매뉴얼...**: 네덜란드 암스테르담 대학교에서 공식 유지관리하는 방대한 Praat 도움말 웹페이지로 연결됩니다.
- **WebPraat 정보...**: 버전 정보, 핵심 엔진 크레딧 및 라이선스 안내 모달 창을 엽니다.

### 언어 전환기
상단 메뉴 바 우측 끝에 위치합니다:
- **EN**: 인터페이스 언어를 오리지널 데스크톱 Praat 영문 표기로 표시합니다.
- **한국어**: 모든 메뉴, 버튼, 대화상자 설명을 표준 한국어 음성음운학 용어로 전환합니다.

## 3. Praat 객체 (Objects) 창

좌측의 Praat 객체 창은 음성 데이터와 분석 결과물을 관리하는 핵심 허브입니다.

### Praat 객체 개념 이해하기
WebPraat에서 불러오거나 계산된 모든 요소는 고유한 번호(ID), 객체 유형, 이름을 가진 **객체(Object)** 형태로 저장됩니다:
- **`Sound`**: 실제 음향 오디오 파형 데이터 (채널 수, 샘플링 주파수, 시간별 진폭 값).
- **`TextGrid`**: 발화 구간 및 특정 시점을 라벨링하는 전사 층 (구간 층 및 지점 층).
- **`Pitch`**: 시간에 따른 성대 진동수이자 억양의 물리적 기반인 기본주파수($F_0$) 궤적.
- **`Formant`**: 모음의 음색을 결정하는 성도 공명 주파수($F_1, F_2, F_3, \dots$) 및 대역폭.
- **`Spectrogram`**: 시간에 따른 주파수별 음향 에너지 분포를 시각화한 2차원 행렬.
- **`Intensity`**: 시간에 따른 음향 에너지의 세기(dB).
- **`PowerCepstrogram` / `CPP`**: 음성 위생 및 음질(Voice quality, 예: 기식음, 애성)을 정량화하는 켑스트럼 피크 척도.

### 객체 선택 및 파일 불러오기
- **단일 선택**: 목록에서 항목을 한 번 클릭하면 선택되며, 우측에 해당 객체 전용 동작 버튼들이 활성화됩니다.
- **다중 선택**: `Ctrl` (Windows/Linux) 또는 `Cmd` (macOS) 키를 누른 채 클릭하면 여러 객체를 동시에 선택할 수 있습니다 (예: `Sound`와 `TextGrid`를 함께 선택할 때 사용).
- **연속 범위 선택**: `Shift` 키를 누른 채 클릭하면 두 항목 사이의 모든 객체가 선택됩니다.
- **더블 클릭**: `Sound` 객체를 더블 클릭하면 **사운드 에디터**가 열리며, `TextGrid` 객체를 더블 클릭하면 **TextGrid 에디터**가 바로 열립니다.
- **끌어다 놓기 (Drag & Drop)**: 탐색기에서 오디오 파일이나 `.TextGrid` 파일을 끌어다 객체 목록 위에 놓으면 즉시 불러와집니다.

### 고정 하단 동작 버튼
객체 창 하단에는 언제나 사용할 수 있는 5개의 기본 도구가 있습니다:
- **이름 변경...**: 선택한 객체의 이름을 수정합니다.
- **복사...**: 선택한 객체와 동일한 데이터를 가진 복제본 객체를 새 이름으로 생성합니다.
- **검사 (Inspect)**: 객체의 내부 데이터 구조와 세부 수치 배열을 정보창에 정밀하게 표시합니다.
- **정보 (Info)**: 객체의 길이, 샘플링 주파수, 프레임 수, 최댓값/최솟값 등의 요약 정보를 정보창에 출력합니다.
- **제거 (Remove)**: 선택한 객체를 메모리에서 완전히 삭제합니다.

### 객체 유형별 동적 동작 (Dynamic Actions)

목록에서 객체를 선택하면 객체 창 우측 패널에 해당 데이터 유형에 특화된 분석 및 변환 명령들이 나타납니다:

#### 1) `Sound` 객체를 선택한 경우
- **`보기 및 편집 (View & Edit)`**: 파형과 스펙트로그램을 사운드 에디터 창에 엽니다.
- **`재생` / `정지`**: 전체 사운드를 스피커나 이어폰으로 즉시 재생하거나 멈춥니다.
- **`그리기...`**: 사운드 파형을 Praat 그림창(Picture)에 벡터 그래픽으로 그립니다.
- **`피치 추출 (To Pitch)...`**: 자기상관(Autocorrelation) 알고리즘을 사용해 기본주파수($F_0$) 윤곽선을 계산합니다.
  - *파라미터*: 시간 간격(초), 최저 피치 하한(Hz, 기본값 75 Hz), 최고 피치 상한(Hz, 기본값 500 Hz).
- **`포먼트 분석 (Burg)...`**: Burg의 선형 예측 분석법으로 모음 포먼트 주파수를 추출합니다.
  - *파라미터*: 최대 포먼트 개수 (인간 음성의 경우 일반적으로 5개), 포먼트 상한 (여성/아동 음성은 5500 Hz, 성인 남성 음성은 5000 Hz 권장), 윈도우 길이(초).
- **`스펙트로그램 생성...`**: 시간-주파수 스펙트럼 에너지를 계산합니다.
  - *파라미터*: 윈도우 길이 (광대역 분석은 0.005초, 협대역 배음 분석은 0.03초), 최대 주파수(Hz).
- **`음향 강도 분석 (To Intensity)...`**: 시간 경과에 따른 음향 강도(dB) 곡선을 계산합니다.
- **`TextGrid 생성...`**: 해당 사운드의 시작 및 종료 시간과 정확히 일치하는 빈 주석 템플릿을 생성합니다.
  - *파라미터*: `모든 티어(Tier) 이름` (예: `sentence word phone`), `포인트(Point) 티어 지정`.
- **고급 DSP 모듈**:
  - `파워 켑스트로그램 분석 (PowerCepstrogram)...`: 켑스트럼 표현을 계산합니다.
  - `선형예측부호화 분석 (LPC burg)...`: 음성 필터 계수를 모델링합니다.
  - `멜 주파수 켑스트럼 분석 (MFCC)...`: 음성 인식 및 화자 식별용 멜 계수를 추출합니다.
  - `KlattGrid 변환 (단순)...`: 음성 합성 파라미터를 추출합니다.
- **조회 (Query) 명령 (음향 측정 수치 확인)**:
  - `채널 수 확인`: 모노(1) 또는 스테레오(2) 확인.
  - `샘플 수 확인`: 전체 오디오 샘플 포인트 개수.
  - `샘플링 주파수 확인`: 헤르츠(Hz) 단위의 샘플링 레이트 (예: 44100 Hz).
  - `샘플링 주기 확인`: 샘플 1개가 차지하는 시간 간격 ($\Delta t = 1 / f_s$).
  - `총 길이 확인`: 음성 파일의 전체 지속 시간(초).
  - `평균값 가져오기...`: 지정한 시간 구간 내의 평균 진폭값.
  - `제곱평균제곱근(RMS) 가져오기...`: 지정 구간의 RMS 실효 진폭 에너지.
  - `특정 시점 값 가져오기...`: 특정 초(second) 시점의 순간 진폭값.

#### 2) `Pitch` 객체를 선택한 경우
- **`그리기...`**: 기본주파수 윤곽선을 Praat 그림창에 연속된 선으로 그립니다.
- **`산점도 그리기 (Speckle)...`**: 개별 피치 후보 프레임을 점 형태로 그림창에 그립니다.
- **`평균 피치(F0) 가져오기...`**: 특정 구간 내의 평균 기본주파수(Hz)를 계산해 정보창에 출력합니다.
- **`특정 시점 피치 가져오기...`**: 특정 시점의 $F_0$ 수치를 조회합니다.
- **`유성음 프레임 수 세기`**: 성대 진동이 감지된 유성음 구간 프레임 개수를 반환합니다.
- **합성 (Synthesise)**:
  - `사운드로 변환 (펄스)`: 피치 윤곽선에 따른 성대 펄스 열(Pulse train) 사운드를 합성합니다.
  - `사운드로 변환 (허밍)`: 피치 궤적을 따라 흥얼거리는 듯한 허밍 사운드를 합성합니다.
  - `사운드로 변환 (사인파)...`: 기본주파수 변화를 부드러운 사인파 톤으로 합성합니다.

#### 3) `Formant` 객체를 선택한 경우
- **`그리기...` / `산점도 그리기 (Speckle)...`**: 포먼트 궤적($F_1, F_2, F_3$)을 그림창에 시각화합니다.
- **`테이블로 변환...`**: 시간 프레임별 포먼트 주파수와 대역폭을 스프레드시트 형태의 테이블 데이터로 변환합니다.
- **`포먼트 트랙 추적...`**: 후보 주파수들 사이에서 연속적인 최적 포먼트 경로를 추적합니다.

#### 4) `Spectrogram` 객체를 선택한 경우
- **`스펙트로그램 칠하기 (Paint)...`**: 스펙트로그램의 농담(음향 에너지)을 그림창에 인쇄용으로 칠합니다.
- **`스펙트럼 슬라이스 생성...`**: 특정 시점의 고속 푸리에 변환(FFT) 단면 스펙트럼 슬라이스를 추출합니다.

#### 5) `TextGrid` 객체를 선택한 경우
- **`보기 및 편집 (View & Edit)`**: 전사 층 편집기를 엽니다.
- **`TextGrid 내보내기...`**: 전사 내용을 텍스트 파일로 내보냅니다.
- **`그리기...`**: 주석 층의 경계선과 라벨 텍스트를 그림창에 그립니다.

#### 6) `Sound`와 `TextGrid`를 함께 선택한 경우 (다중 선택)
- **`보기 및 편집 (View & Edit)`**: 상단에는 사운드 파형과 스펙트로그램, 하단에는 전사 층(Tier)이 완전히 연동된 **통합 음성 분절 전사 에디터**를 실행합니다.

## 4. 사운드 에디터: 파형 및 스펙트로그램

**사운드 에디터**는 음성의 음향학적 특징을 정밀하게 관찰하고 측정할 수 있는 핵심 화면입니다.

```
+-------------------------------------------------------------------+
|  [파형 캔버스]                상대 진폭 (-1.0 ~ +1.0)              |
|                                                                   |
+-------------------------------------------------------------------+
|  [스펙트로그램 캔버스]        주파수 (0 ~ 5000 Hz)                 |
|   ~ ~ ~ ~ ~ ~ (피치: 파란색 실선) ~ ~ ~ ~ ~ ~                     |
|   . . . . . . (포먼트: 빨간색 점) . . . . .                       |
|   - - - - - - (음향 강도: 초록색 곡선) - - - -                    |
+-------------------------------------------------------------------+
| [전체] [확대] [축소] [선택] [이전] | [화면영역 재생] [선택영역 재생] |
+-------------------------------------------------------------------+
```

### 사운드 에디터 열기
객체 목록에서 `Sound` 객체를 선택한 후 **보기 및 편집 (View & Edit)** 버튼을 클릭하거나, 해당 사운드 객체를 더블 클릭합니다.

### 파형 표시
상단 캔버스에는 시간 경과에 따른 공기 압력의 변화인 진폭 파형이 그려집니다.
- **세로축**: 정규화된 상대 음압 진폭 ($-1.0 \sim +1.0$).
- **가로축**: 초(second) 단위의 시간.
- **영점 기준선**: 대기압 평형 상태를 나타내는 가운데 점선.

### 스펙트로그램 표시
하단 캔버스에는 시간에 따른 주파수별 음향 에너지가 2차원으로 시각화됩니다:
- **세로축**: $0\text{ Hz}$부터 상한(일반적으로 $5000\text{ Hz}$)까지의 주파수.
- **가로축**: 시간(초).
- **명암 및 색상 농도**: 데시벨(dB) 단위의 음향 에너지 세기입니다. 짙게 나타나는 가로 띠는 모음의 주요 공명 대역인 포먼트나 마찰음의 잡음 에너지 대역을 의미합니다.
- **흑백 / 컬러 전환**: 논문 인쇄에 적합한 클래식 흑백 모드와 가독성이 뛰어난 컬러 히트맵 모드를 상단 체크박스에서 전환할 수 있습니다.

### 음향 분석 오버레이
에디터 상단의 옵션을 켜고 끄며 실시간 음향 분석 곡선을 덧씌울 수 있습니다:
- **피치(F0) 표시 (파란색 실선)**: 성대 진동수 윤곽선을 표시합니다. 억양, 성조, 성대 진동 유무를 분석할 때 사용합니다.
- **포먼트 표시 (빨간색 점)**: 추정된 공명 주파수($F_1 \sim F_5$)의 중심 위치를 붉은 점으로 표시합니다. 모음 삼각도나 자음의 전이(Transition) 구간 분석에 필수적입니다.
- **음향 강도 표시 (초록색 곡선)**: 데시벨($\text{dB}$) 단위의 에너지 세기를 곡선으로 표시하여 음절의 강세 구조와 음량을 한눈에 보여줍니다.

### 탐색 및 화면 확대/축소
에디터 좌측 하단에 위치한 5개의 줌 버튼으로 원하는 구간을 신속하게 탐색할 수 있습니다:
- **`전체 (all)`**: 오디오 파일 전체를 한 화면에 다 보여주도록 줌아웃합니다.
- **`확대 (in)`**: 현재 화면 중심을 기준으로 2배 확대합니다.
- **`축소 (out)`**: 현재 화면을 2배 축소합니다.
- **`선택 (sel)`**: 마우스로 드래그하여 강조 표시한 선택 영역만 화면 가득 차게 확대합니다.
- **`이전 (bak)`**: 직전에 보았던 확대/축소 화면 비율로 되돌아갑니다.

### 오디오 재생 및 구간 선택
- **시간 구간 선택**: 파형이나 스펙트로그램 캔버스 위에서 마우스를 가로로 드래그하면 해당 시간 구간이 강조 표시됩니다.
- **단일 커서 배치**: 캔버스의 특정 지점을 한 번 클릭하면 드래그 범위 없이 해당 시점에 수직 커서 선이 놓입니다.
- **선택 영역 재생**: 키보드의 **`스페이스바(Spacebar)`**를 누르거나 하단 중앙의 선택 영역 재생 바를 클릭하면 선택된 음성만 소리로 재생됩니다.
- **화면 영역 재생**: 하단 전체 재생 바를 클릭하면 현재 화면에 보이는 가시 구간 전체를 재생합니다.
- **실시간 재생 헤드**: 오디오가 재생되는 동안 수직 재생 헤드가 파형 위를 실시간으로 부드럽게 지나갑니다.

## 5. TextGrid 에디터 및 음성 전사

**TextGrid 에디터**는 음성학에서 오디오 신호의 경계를 나누고 단어, 음소, 음절 등을 텍스트로 라벨링(Segmentation & Labeling)하는 핵심 도구입니다.

```
+-------------------------------------------------------------------+
| 파일  편집  조회  선택  구간  경계  층                            |
+-------------------------------------------------------------------+
|  [파형 캔버스]                                                    |
+-------------------------------------------------------------------+
|  [텍스트 입력창:  | kʰ |             ] [IPA 팔레트 ▼]             |
+-------------------------------------------------------------------+
| 1번 층 (words)    |      cat      |          sat          |   |
| 2번 층 (phones)   | kʰ | æ |  t   |   s   |   æ   |   t   |   |
+-------------------------------------------------------------------+
```

### TextGrid란 무엇인가?
TextGrid는 여러 층(Tier)으로 구성된 Praat 고유의 발화 주석 파일 포맷입니다:
- **구간 층 (Interval Tier)**: 시작 시간과 종료 시간을 가지는 연속적인 구간들을 라벨링합니다 (예: 단어 층, 음소 층, 음절 층).
- **지점 층 (Point Tier)**: 시간의 폭이 없는 특정 순간을 점(Point) 마커로 기록합니다 (예: 파열음의 파열 순간 Burst, 성조 타깃 시점, 피치 정점).

### 사운드와 TextGrid 함께 열기
소리를 들으면서 파형과 함께 전사하려면:
1. 객체 창에서 작업할 `Sound` 객체를 클릭합니다.
2. `Ctrl` (또는 `Cmd`) 키를 누른 채 짝이 되는 `TextGrid` 객체를 클릭하여 두 객체를 모두 파랗게 선택합니다.
3. **`보기 및 편집 (View & Edit)`** 버튼을 누릅니다. 상단에 파형과 재생 바, 하단에 다층 전사 트랙이 배치된 통합 전사 창이 실행됩니다.

### 경계 추가 및 이동 조작
- **대화형 커서 원형 버튼**: 파형이나 주석 층 위를 클릭하면 수직 커서 선이 나타나며, 각 층의 상단 경계선에 작은 원형 단추가 표시됩니다:
  - **특정 층의 원형 단추를 클릭**: 해당 층의 현재 커서 위치에만 경계선이 생성됩니다.
  - **최상단 원형 단추를 클릭**: 연결된 **모든 층의 동일한 시간 위치**에 한 번에 경계선이 일괄 생성됩니다.
- **키보드 단축키**:
  - **`Enter` 키**: 현재 선택된 층의 커서 위치에 즉시 경계를 추가합니다.
  - **`Ctrl + Enter`** (또는 `Cmd + Enter`): 모든 층의 커서 위치에 동시에 경계를 추가합니다.
  - **`Alt + Backspace`**: 커서에 가장 인접한 경계선을 삭제합니다.
- **경계선 드래그 이동**: 이미 생성된 세로 경계선을 마우스로 잡고 좌우로 드래그하면 파열 시점이나 무성/유성 전환점에 맞춰 경계 시간을 미세하게 조정할 수 있습니다.

### 라벨 입력 및 IPA 문자 팔레트
- **텍스트 입력**: 임의의 구간을 클릭해 활성화한 뒤 키보드로 라벨 텍스트를 입력하거나, 에디터 상단의 텍스트 입력창에서 직접 수정합니다.
- **구간 간 연속 이동**:
  - **`Tab` 키**: 바로 **다음 구간**으로 선택을 넘깁니다.
  - **`Shift + Tab` 키**: 바로 **이전 구간**으로 선택을 되돌립니다.
- **유니코드 국제음성기호(IPA) 팔레트**: 에디터 상단의 **IPA** 버튼을 누르면 자음, 모음, 발음 구별 부호(Diacritics), 초분절 부호가 분류된 특수문자 팔레트가 열립니다. 원하는 기호(예: `ə`, `ɪ`, `ʃ`, `θ`, `ŋ`, `kʰ`)를 클릭하면 활성화된 구간에 즉시 입력됩니다.

### TextGrid 메뉴 상세 참조

#### 파일 (File) 메뉴
- **TextGrid 파일로 저장...**: 작업한 주석을 `.TextGrid` 파일로 내보냅니다.
  - *빠른 저장 단축키*: **`Ctrl + S`** (또는 `Cmd + S`)를 누르면 즉시 저장됩니다. 로컬 폴더를 마운트한 상태라면 컴퓨터 하드 드라이브의 원본 파일에 실시간으로 즉시 덮어쓰기 저장됩니다!
- **닫기 (Close)**: 전사 창을 닫고 객체 목록 화면으로 돌아갑니다.

#### 편집 (Edit) 메뉴
- **실행 취소 (Undo) (`Ctrl + Z` / `Cmd + Z`)**: 경계 생성, 삭제, 이동, 텍스트 변경 등 직전에 수행한 작업을 이전 상태로 되돌립니다.
- **다시 실행 (Redo) (`Ctrl + Y` / `Cmd + Y`)**: 취소했던 작업을 다시 적용합니다.
- **텍스트 잘라내기 / 복사 / 붙여넣기**: 구간 라벨 문자열을 클립보드로 편집합니다.

#### 조회 (Query) 메뉴
- **커서 위치 시간 조회**: 현재 커서의 정확한 시간(초)을 정보창에 출력합니다.
- **선택 시작 / 종료 시간 / 구간 길이 조회**: 현재 선택된 구간의 시작점, 끝점, 전체 지속 시간을 측정합니다.
- **구간 라벨 조회**: 선택된 구간의 텍스트 라벨을 정보창에 표시합니다.
- **층(Tier) 개수 조회**: 전체 층의 개수를 확인합니다.
- **구간 개수 조회**: 현재 층에 나뉘어 있는 구간의 총 개수를 반환합니다.

#### 선택 (Select) 메뉴
- **커서를 선택 시작점으로 이동**: 커서를 활성 구간의 왼쪽 경계로 즉시 이동합니다.
- **커서를 선택 종료점으로 이동**: 커서를 활성 구간의 오른쪽 경계로 이동합니다.
- **이전 구간 선택 (`Shift + Tab`)**: 선택을 왼쪽 구간으로 한 칸 옮깁니다.
- **다음 구간 선택 (`Tab`)**: 선택을 오른쪽 구간으로 한 칸 옮깁니다.

#### 구간 (Interval) 메뉴
- **층에 새 구간 생성...**: 현재 마우스로 드래그해 놓은 선택 영역의 시작과 끝에 두 개의 경계를 동시에 삽입하여 독립된 새 구간을 만듭니다.
- **구간 삭제**: 선택된 구간의 경계를 제거하고 양옆의 인접 구간과 하나로 합칩니다.
- **구간 텍스트 설정...**: 대화상자를 열어 구간의 라벨 텍스트를 입력하거나 수정합니다.
- **구간 텍스트 지우기**: 구간의 경계선 구조는 그대로 유지한 채 안의 라벨 텍스트만 비웁니다.

#### 경계 (Boundary) 메뉴
- **현재 층의 커서 위치에 경계 추가... (`Enter`)**: 활성 층의 커서 자리에 경계선을 놓습니다.
- **모든 층의 커서 위치에 경계 추가 (`Ctrl/Cmd + Enter`)**: 모든 층에 일괄 경계를 추가합니다.
- **커서 위치의 경계 삭제 (`Alt + Backspace`)**: 커서 바로 아래의 경계선을 지웁니다.
- **가장 가까운 경계를 커서로 이동**: 가장 가까운 경계선을 현재 커서가 놓인 위치로 끌어옵니다.

#### 층 (Tier) 메뉴
- **구간 층(Interval Tier) 추가...**: 층 이름과 삽입할 위치 번호(1 = 맨 위)를 지정하여 새 구간 층을 추가합니다.
- **지점 층(Point Tier) 추가...**: 특정 순간을 마킹하기 위한 지점 층을 추가합니다.
- **층 복제...**: 기존 층의 모든 경계와 라벨이 복사된 새 층을 복제 생성합니다.
- **층 이름 변경...**: 선택된 층의 이름을 수정합니다.
- **층 삭제**: 선택된 층을 안전 확인 절차를 거친 후 완전히 제거합니다.

## 6. Praat 그림 (Picture): 고품질 논문용 그림 생성

**Praat 그림 (Picture)** 탭은 학기말 소논문, 과제물 제출, 학술 대회 발표 자료용으로 왜곡 없는 정밀한 고해상도 벡터 그래프를 제작하는 공간입니다.

### 그림 용지 및 뷰포트 선택
- Praat 그림창은 표준 **12" × 12" 출판용 캔버스**를 모사합니다.
- **외부 뷰포트 (인치) 선택**: 흰색 캔버스 위에서 마우스를 드래그하여 그래프가 그려질 사각형 영역(가로, 세로 인치 단위)을 지정합니다.
- 지정된 박스 안으로 객체 목록의 `그리기...`나 `스펙트로그램 칠하기 (Paint)...` 명령의 결과물이 정확하게 그려집니다.

### 파형, 스펙트로그램 및 윤곽선 그리기
1. **Praat 그림** 탭에서 마우스를 드래그하여 상단에 박스를 하나 만듭니다 (예: 가로 1.0 ~ 5.0인치, 세로 1.0 ~ 3.0인치).
2. **Praat 객체** 창으로 이동하여 `Sound` 객체를 선택하고 **`그리기...`**를 누릅니다.
3. 시작/종료 시간을 지정하고 확인을 누르면 상단 박스 안에 깨끗한 음향 파형이 그려집니다.
4. 다시 그림 탭으로 돌아와 방금 그린 파형 바로 아래에 두 번째 박스를 드래그하고, 이번에는 `Spectrogram` 객체를 선택한 뒤 **`스펙트로그램 칠하기 (Paint)...`**를 실행하면 논문에서 흔히 볼 수 있는 이상적인 파형-스펙트로그램 결합 그림이 완성됩니다!

### 스타일, 축 및 제목 설정
그림 탭의 툴바를 통해 그림의 세부 양식을 편집할 수 있습니다:
- **색상**: 검정, 빨강, 파랑, 초록 등 Praat 표준 펜 색상을 지정합니다.
- **선 두께**: 선의 굵기(1.0, 1.5, 2.0 등)를 조절합니다.
- **선 스타일**: 실선(Solid), 점선(Dotted), 파선(Dashed), 일점쇄선(Dash-dotted)을 선택할 수 있습니다.
- **글꼴 크기**: 축 눈금 및 라벨 글자 크기(10, 12, 14, 18, 24 pt)를 설정합니다.
- **내부 테두리 그리기**: 활성 뷰포트 박스 둘레에 깔끔한 외곽 프레임 사각형을 그립니다.
- **상단 제목 추가...**: 그래프 상단 중앙에 제목이나 캡션 텍스트를 입력합니다.
- **축 장식 (Garnish)**: 그리기 대화상자에서 체크하면 주파수(Hz) 및 시간(초) 좌표축과 눈금 수치가 자동으로 예쁘게 그려집니다.
- **모두 지우기 (Erase all)**: 캔버스를 백지 상태로 깨끗이 초기화합니다.

### 그림 파일 내보내기
완성된 그림은 두 가지 포맷으로 저장할 수 있습니다:
- **PNG 파일로 저장...**: MS Word, 한글(HWP), PowerPoint 슬라이드에 바로 붙여넣을 수 있는 고해상도 래스터 이미지 파일로 다운로드합니다.
- **SVG 벡터 파일로 저장...**: 인쇄 시 아무리 크게 확대해도 선이나 글자가 깨지지 않는 벡터 그래픽(`.svg`) 파일로 내보냅니다.

## 7. 사운드 녹음기: 마이크 오디오 캡처

별도의 외부 녹음 프로그램을 설치할 필요 없이 웹 브라우저 안에서 발화 음성을 직접 녹음하고 분석할 수 있습니다.

### 녹음 환경 설정
1. 상단 메뉴에서 **`새로 만들기 > 모노 사운드 녹음...`** (또는 `스테레오 사운드 녹음...`)을 클릭합니다.
2. 브라우저에서 마이크 사용 권한을 요청하면 **허용**을 누릅니다.
3. 옵션을 확인합니다:
   - **입력 장치**: 내장 마이크 또는 연결된 외장 USB 마이크/오디오 인터페이스를 선택합니다.
   - **샘플링 주파수**: 음향 분석 용도에 맞게 설정합니다 (일반 음성학 분석은 `44100 Hz`, 음성 인식 전처리용은 `16000 Hz` 권장).
   - **객체 이름**: 저장될 사운드 이름을 입력합니다 (기본값: `untitled`).

### 입력 레벨 모니터링 및 클리핑 방지
- 마이크에 대고 말하면서 실시간 **입력 레벨 미터**를 확인합니다:
  - **초록색 / 노란색 범위**: 신호 대 잡음비가 양호한 최적의 입력 상태입니다.
  - **빨간색 / `클리핑(CLIP)` 경고**: 소리가 너무 커서 음성 파형의 위아래가 잘려 나가는 왜곡 현상이 발생한 상태입니다. 마이크 입력 볼륨을 낮추거나 입과 마이크 사이의 거리를 약간 두어야 합니다.
- 실시간 오실로스코프를 통해 녹음되는 파형의 모양을 시각적으로 미리 확인할 수 있습니다.

### 객체 목록에 저장
1. **`녹음 (Record)`** 버튼을 누르고 녹음을 시작합니다.
2. 분석할 단어나 문장을 자연스럽게 발음합니다.
3. 발화가 끝나면 **`정지 (Stop)`** 버튼을 누릅니다.
4. **`재생 (Play)`** 버튼으로 녹음된 음질을 들어보고 잡음 유무를 확인합니다.
5. **`목록에 저장 후 닫기`** (또는 `목록에 저장`)를 누르면 녹음된 음성이 좌측 Praat 객체 목록에 새 `Sound` 객체로 즉시 추가됩니다.

## 8. Praat 스크립트: 음성학 분석 자동화

반복적인 음향 측정 작업(예: 피험자 50명의 모음 녹음에서 F1, F2 값 일괄 추출하기)이나 수백 개의 문장을 연속으로 전사하는 작업은 Praat 스크립트로 손쉽게 자동화할 수 있습니다.

### 스크립트 작성 및 열기
- 상단 탭에서 **Praat 스크립트** 탭을 클릭하거나, 메뉴에서 **`Praat > 새 Praat 스크립트`** 또는 **`Praat 스크립트 열기...`**를 선택합니다.
- 내장 에디터는 Praat 스크립트 전용 문법 강조(Syntax highlighting), 줄 번호 표시, 자동 들여쓰기를 완벽하게 지원합니다.
- **샘플 스크립트...** 드롭다운 메뉴에서 음성학 수업에서 자주 쓰이는 기본 예제들을 바로 불러와 참고할 수 있습니다:
  - *반복문 및 수학 계산*
  - *프로시저 및 문자열 처리*
  - *변수 일괄 연산*
  - *Praat 그림창(Picture) 벡터 드로잉*

### 스크립트 실행 및 결과 확인
- 스크립트 상단 툴바의 **`실행 (Run)`** 버튼을 누르거나 키보드의 **`Ctrl + Enter`** (또는 `Cmd + Enter`)를 누릅니다.
- 스크립트 안에서 `writeInfoLine:`이나 `appendInfoLine:`으로 출력한 결과는 우측 하단의 **Praat 정보 (Info)** 창에 일목요연하게 기록됩니다.

### 대화형 폼 (`form ... endform`)
스크립트 시작 부분에 다음과 같은 Praat 표준 폼 선언문이 작성되어 있는 경우:
```praat
form 수동 전사 보조
    sentence Wav_folder
    integer Start_from 1
    boolean Skip_done 1
endform
```
WebPraat은 스크립트 실행 직전 자동으로 전용 입력 대화상자(Modal)를 띄워줍니다. 텍스트 입력, 숫자 설정, 체크박스 선택을 마우스로 조작한 후 확인을 누르면 지정한 값이 스크립트 변수로 안전하게 전달됩니다.

### 플로팅 일시 정지 창 (`[Next]` / `[Stop]`)
연속 음성 전사 스크립트처럼 중간에 학생이 에디터 창에서 작업을 마칠 때까지 스크립트가 대기해야 하는 경우 Praat의 `beginPause / endPause` 문법을 사용합니다:
```praat
beginPause: "전사 작업"
    comment: "View 창에서 분절 작업을 진행하세요."
    comment: "작업 완료 후 Next 버튼을 누르세요."
clicked = endPause: "Stop", "Next", 2
```
이 코드가 실행되면:
1. WebPraat은 스크립트 실행을 일시 중단하고 화면 상단에 드래그 가능한 **플로팅 일시 정지 창**을 띄웁니다.
2. 이때 **작업 공간의 다른 모든 기능은 정상 작동**하므로, 학생은 자유롭게 소리를 재생하고 파형을 확대하며 TextGrid에 경계를 넣고 라벨을 입력할 수 있습니다.
3. 작업이 끝나면 **`Ctrl + S`**로 저장한 뒤 일시 정지 창의 **`[Next]`** 버튼을 누릅니다. 스크립트가 즉시 다음 파일로 넘어가 작업을 이어갑니다!

### 일괄 처리를 위한 로컬 폴더 마운트
컴퓨터에 저장된 음성 말뭉치 폴더 전체를 다루려면:
1. 스크립트 탭의 **`폴더 마운트...`** 버튼이나 메뉴의 **`열기 > 로컬 폴더 마운트...`**를 클릭합니다.
2. 음성 파일들이 들어 있는 로컬 폴더를 지정하고 브라우저 권한을 승인합니다.
3. 해당 폴더가 가상 디렉토리 `/workspace/<폴더이름>` 경로로 연결됩니다. 스크립트의 `Create Strings as file list:`나 `Read from file:` 구문이 로컬 파일들을 직접 읽어 들이며 작업을 수행할 수 있습니다.

## 9. 정보창 및 작업 공간 보존

### 음향 측정값 조회 결과 확인
사운드나 피치 객체에서 수치 조회 명령(예: `총 길이 확인`, `평균 피치(F0) 가져오기...`, `제곱평균제곱근(RMS) 가져오기...`)을 내리면 그 결과가 우측 하단 **Praat 정보 (Info)** 창에 기록됩니다:
- **복사** 버튼: 출력된 측정 텍스트 전체를 한 번에 클립보드로 복사하여 엑셀(Excel), R, 논문 원고에 즉시 붙여넣을 수 있습니다.
- **지우기** 버튼: 누적된 이전 조회 기록을 지워 콘솔을 깨끗하게 정리합니다.

### 브라우저 작업 공간 자동 저장
WebPraat은 웹 브라우저의 최신 기술인 **OPFS(Origin Private File System)**를 이용하여 사용자의 작업 상태를 실시간으로 자동 보존합니다:
- 웹 브라우저 창을 실수로 닫거나 새로고침하더라도, 작업 중이던 객체 목록과 스크립트 내용이 자동으로 복구됩니다.
- 상단 메뉴의 **`Praat > 작업 공간 저장 (OPFS)`**을 통해 언제든 수동 저장이 가능하며, 새 마음으로 초기화하고 싶을 때는 **`Praat > 저장된 작업 공간 초기화`**를 누르면 됩니다.

## 10. 단축키 일람표

작업 효율을 극대화해 주는 핵심 단축키 목록입니다:

| 영역 | 단축키 | 동작 |
| :--- | :--- | :--- |
| **전역 / 에디터 공통** | `Ctrl + Z` / `Cmd + Z` | 직전 작업 **실행 취소 (Undo)** |
| | `Ctrl + Y` / `Cmd + Y` | 취소한 작업 **다시 실행 (Redo)** |
| | `Ctrl + Shift + Z` / `Cmd + Shift + Z` | 대체 **다시 실행 (Redo)** |
| | `Ctrl + S` / `Cmd + S` | 활성 TextGrid **빠른 저장 (Quick Save)** |
| **오디오 재생** | `Spacebar` (스페이스바) | 선택 구간 **재생 / 정지** |
| **화면 확대 및 축소** | `Ctrl + A` / `Cmd + A` | **전체 (all)** 보기 (오디오 전체 화면 맞춤) |
| | `Ctrl + I` / `Cmd + I` | 화면 **확대 (in)** |
| | `Ctrl + O` / `Cmd + O` | 화면 **축소 (out)** |
| **TextGrid 음성 전사** | `Enter` | 현재 층의 커서 위치에 **경계 추가** |
| | `Ctrl + Enter` / `Cmd + Enter` | **모든 층**의 커서 위치에 동시에 **경계 추가** |
| | `Alt + Backspace` | 커서 위치의 **경계 삭제** |
| | `Tab` | **다음 구간**으로 선택 이동 |
| | `Shift + Tab` | **이전 구간**으로 선택 이동 |
| **스크립트 콘솔** | `Ctrl + Enter` / `Cmd + Enter` | 작성한 Praat 스크립트 **실행 (Run)** |
